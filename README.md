# -rhyanriello.github.io
Portfólio pessoal de Rhyan Riello

## Abertura do portfólio

A assinatura cromada abre a primeira visita de cada sessão sobre o próprio site,
com desfoque, aproximação e recuo. O som é opcional. A página fica disponível
ao terminar, ao pular ou caso a mídia não consiga reproduzir.

- `intro.js` sincroniza a revelação com o vídeo.
- `intro.css` mantém a composição responsiva.
- `assets/intro-metal-cinema-v1.mp4` contém somente a assinatura e os efeitos.
- O rodapé oferece **Rever abertura**; `?intro=1` também solicita a reprodução.
- A preferência de movimento reduzido e os links diretos para seções são respeitados.
